## How the coach uses this

- Before planning a week, check if any event overlaps that week's dates.
- Apply the event's **running window** and **strength** constraint per day.
- On big-opportunity days (e.g. 2h free morning), place the long run / key session.
- Move strength to unconstrained days; skip if no day fits (don't force onto travel days).
