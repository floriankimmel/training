## How the coach uses this

- Before planning a week, check if any event overlaps that week's dates.
- Apply the event's **running window** and **strength** constraint per day.
- On big-opportunity days (e.g. 2h free morning), place the long run / key session.
- Move strength to unconstrained days; skip if no day fits (don't force onto travel days).

## Recurring Travel Profiles

### Göteborg work trip (typical)

- **Pattern**: fly out **Monday afternoon**, back **Thursday afternoon**.
- **Training days**: **Tue / Wed / Thu** — run at ~06:00, work starts ~09:00 → **up to 2h available**.
- **Use for**: long run or a big aerobic/vert-accumulation block (great for trail volume).
- **Strength**: **not possible** on trip days → shift Kraft to Mon (before flight) / Fri / weekend, or skip that week's overflow.
- **Mon**: travel day — light/easy or rest. **Thu**: possible AM run before afternoon flight.
